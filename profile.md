# Profile

This is a template blog built with Next.js 16, Tailwind CSS v4, and a Tolaria vault as a Git submodule for content.

Replace this `profile.md` with your own details — name, bio, social links, and the About page content below. The source code contains **no personal information**; everything here drives the site.

## Why a template?

Fork it, point the `content/` submodule at your own Tolaria vault, edit `profile.md`, and you have a blog.
